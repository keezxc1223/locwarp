安裝總覽4 個步驟

第一次使用需要完成以下四步，之後更新都在程式內完成，不用再重來一次。

開始之前，先準備好
  • Windows 10 / 11 電腦64 位元，並且有系統管理員權限。
  • iPhone，iOS 17 以上iOS 16 由社群維護，iOS 15 以下不支援。
  • 可傳資料的 USB 線原廠線最穩，很多副廠線只能充電。
  • 同一個 WiFi（選用）想拔線改用無線時才需要，第一次仍要先用 USB。
下載並安裝LocWarp 安裝檔 USB driveriTunes 或 Apple Devices 信任電腦USB 接上並按信任 開發者模式iPhone 設定裡開啟

  1. Step 1下載並安裝 LocWarp

    抓最新版的 Windows 安裝檔，檔名像 LocWarp-Setup-X.X.XXX.exe。兩個來源內容相同，上方的「下載 Windows 安裝檔」會直接下載 GitHub 上的最新版。

    出現「Windows 已保護您的電腦」
    LocWarp 沒有做數位簽章，第一次執行會被 SmartScreen 擋。點「其他資訊」再點「仍要執行」即可。
    安裝與執行都需要系統管理員權限
    WiFi Tunnel 需要建立虛擬網路介面，所以安裝時會要求管理員權限，每次開啟也會跳 UAC。
    防毒軟體把後端程式隔離
    開啟後若提示後端程式不存在，是防毒把未簽章的 exe 刪了。先把安裝資料夾加入防毒的排除清單，再重新安裝一次。
    之後更新不用重抓安裝檔
    有新版時，程式右下角的版本號旁會出現 NEW。點它再按「下載更新」，下載完成後按「重新啟動」就是新版，座標與設定都會保留。v0.2.205 以前的版本沒有這個功能，需要手動安裝一次新版。

  2. Step 2安裝 Apple USB driver

    Windows 沒有內建 Apple 的 USB driver。下列三種擇一安裝即可，多數人裝桌面版 iTunes 就能用。

    多數人用這個 桌面版 iTunes 64-bit 安裝檔，直接下載 Store 版 iTunes 從 Microsoft Store 安裝 Apple Devices iTunes 抓不到時改用這個
    iTunes 抓不到 iPhone
    社群回報改裝 Microsoft Store 的 Apple Devices 可以成功。

  3. Step 3USB 連接並信任電腦

    用原廠或支援資料傳輸的 USB 線接上 iPhone。iPhone 跳出「要信任這部電腦嗎？」時點「信任」並輸入密碼。

    沒跳提示、或電腦抓不到手機
    先打開 iTunes 或 Apple Devices 看有沒有偵測到裝置。連 iTunes 都看不到，多半是線或孔的問題：
    • 很多副廠線、附贈線只能充電，沒有資料腳位。換原廠線或標示支援資料傳輸的線。
    • 接頭鬆動或進灰塵會時好時壞，換線並清乾淨兩端。
    • 改插主機板後方的 USB 孔，避開前面板、延長線、USB hub 與螢幕上的孔。
    • USB 3.x（藍色孔）對 iPhone 有時反而不穩，試試 USB 2.0（黑色孔），反過來也試。
    • iPhone 要解鎖並停在桌面。之前誤按「不信任」的話，到「設定 › 一般 › 移轉或重置 iPhone › 重置 › 重置位置與隱私權」，重插就會再問一次。
    • 最後才試 iPhone 與電腦各重開一次。

  4. Step 4開啟開發者模式

    在 iPhone 上前往：

    設定隱私權與安全性開發者模式

    打開開關，iPhone 會要求重新啟動。重啟後再確認一次「啟用」並輸入密碼。

    設定裡找不到「開發者模式」
    iOS 16 以上預設不顯示這個選項。用 USB 把 iPhone 連上 LocWarp，到程式上方的「設定」頁按「開啟開發者模式」。接著在 iPhone 上把「設定」App 完全關掉再重開，進到「隱私權與安全性」往下拉就會看到。

完成，可以開始使用了

開啟 LocWarp、USB 接上 iPhone，程式會自動抓到裝置，在地圖上按右鍵就能瞬移。要改用無線時，到「連線」頁按「掃描 WiFi 裝置」或啟動 WiFi Tunnel，成功後即可拔掉 USB（需 iOS 17 以上，且先用 USB 配對過一次）。

WiFi 與連線

WiFi 連不上、Tunnel 啟動逾時
先解鎖 iPhone 再試一次。仍然失敗就按「連線」頁 Start 下方的「連不上?連線診斷」，大約 3 秒會逐項檢查電腦網路、網段、能否連到 iPhone、配對紀錄、Windows 防火牆與自動偵測，直接告訴你是哪一項出問題、該怎麼處理。
Tunnel 啟動後連不上
確認以系統管理員身分啟動，暫時關閉 VPN 或第三方防火牆再試。
WiFi 掃描或自動偵測找不到裝置
確認在同一個 WiFi 網段，路由器沒開裝置隔離（AP isolation），並暫時關閉 VPN 或代理軟體。按「連不上?連線診斷」：顯示防火牆擋住時，按視窗裡的「修復防火牆」；顯示「連得到 iPhone，但自動偵測收不到回應」時，是路由器沒有轉送偵測訊號，直接手動輸入 IP 按 Start 即可，Port 可以留空。
WiFi 每次啟動都要手動連線
到「連線」頁確認目前這台裝置有沒有「釘選」。只要釘選了其他裝置，啟動時就只會自動連線已釘選的那些；頁面上會出現提示，按一下「釘選」即可。
WiFi Tunnel 螢幕暗掉就斷線
把 iPhone 的「自動鎖定」設為永不並接上充電，或在 LocWarp 開啟「螢幕暗掉維持連線」。

其他

No such service: dtservicehub
DDI 沒掛上。失敗時先關閉開發者模式、重開機、再開啟，然後重新掛載。
國旗或地名沒出現
這兩項來自免費公共服務，偶爾會暫時無回應，稍後再瞬移一次即可。
找不到相關問題。可以到 GitHub Issues 回報。
回報問題時請附上：iOS 版本、連線方式，以及 ~/.locwarp/logs/backend.log。WiFi 連不上的問題，請一併附上連線診斷按「複製結果」的內容。狀態列的「Log 資料夾」按鈕可以直接開啟該資料夾。

功能簡介

移動模式

瞬間移動

直接跳到指定座標。

導航移動

沿真實道路前往目的地，走路、腳踏車、開車三檔速度。

多點路徑

依序經過多個點，每站可停留（預設隨機 5 到 20 秒）。圈數設 0 跑一趟，設 N 繞 N 圈，留空無限循環。可勾「點對點跳躍」改成逐點瞬移。

花農專用

在每個路徑點周圍繞圈。繞圈距離、段數、圈數、輪數、前後等待都可自訂，點與點之間可走過去或瞬移。

隨機漫步

在指定半徑內隨機漫遊，每段停頓可調。

搖桿操控

以方向與力度即時操控，支援 WASD 與方向鍵。

速度、路徑與連線

速度

走路10.8腳踏車19.8開車60 km/h
  • 可輸入任意固定速度，或最小到最大的隨機範圍，每段路重新抽一次。
  • 移動中可以改速度後「套用新速度」，不用停下重來。

路徑來源

四個免費免註冊的引擎可切換：OSRM 公用 demo（預設）、OSRM FOSSGIS、Valhalla、BRouter。任一引擎失敗時該段自動改走直線，也可直接勾「使用直線路徑」。多點路徑有「最佳順序」一鍵算出最短走訪順序。

連線

  • USB：插上自動連線，iPhone 鎖定螢幕不受影響。拔除約 4 秒內偵測，重插自動恢復。
  • WiFi Tunnel（iOS 17 以上）：「掃描 WiFi 裝置」會找到同一個 WiFi 上的 iPhone 並連上還沒連線的那些。連過的 IP 會記住，可「釘選」裝置；啟動時會自動補滿剩餘的裝置名額，一台連不上不會拖慢其他台。連不上時按「連不上?連線診斷」，會指出是哪一項出問題。
  • 多裝置：最多同時五台，所有動作同步套用，隨機漫步走一樣的路線。

地圖與座標

  • 圖層：OSM、Google 圖磚（測試）、ESRI 街道與衛星、OpenFreeMap Liberty / Bright / Positron、VersaTiles、NLSC 台灣電子地圖、GSI 日本地理院地圖。全部免 API key。
  • 狀態列顯示目前模擬位置的國旗、地名、天氣與溫度，跨時區時標出時差。
  • 收藏視窗：座標與路線共用同一種操作。上方直接搜尋，點一下座標就移動、點一下路線就載入；右鍵或「⋯」可改名、編輯、移動分類、刪除；可直接拖曳排序；刪除座標後可復原。JSON 與 GPX 匯入匯出，數萬筆顯示在地圖上也不卡。
  • 座標格式：座標系統可選 WGS84、GCJ02（高德、騰訊）、BD09（百度），經緯度順序可切換，顯示、複製、輸入一致。
  • 地址搜尋：免費來源（OpenStreetMap 或 Photon），或自備 Google Geocoding 金鑰。
  • 使用者圖示可換成 6 組內建角色或上傳自己的 PNG。

手機網頁操控

按狀態列的「手機操控」會顯示區網網址與 6 位數 PIN，手機瀏覽器輸入後，底部工具列有瞬移、導航、地點、更多：可搜尋地址、貼上座標、跑路線與種花、隨機漫步、停止與還原。移動中可暫停、繼續、變更速度，也能使用電腦上儲存的座標，或把地點存成座標同步回電腦，並可加到手機主畫面。手機要與電腦在同一個 WiFi，電腦防火牆放行 8777 port。

其他

  • 一鍵還原清除虛擬定位。「停止」只結束移動，定位仍保留，要恢復真實 GPS 請按還原。
  • Cooldown 依瞬移距離自動計算冷卻時間。
  • 介面可在繁體中文與 English 之間切換。
  • 外觀：六種主題色、三段玻璃效果、動畫開關，在「設定 › 外觀」更換。
  • 程式內更新：有新版時點右下角的 NEW 即可下載並更新，不會自動下載。
  • 所有資料存在 ~/.locwarp/，重新安裝不會遺失。
