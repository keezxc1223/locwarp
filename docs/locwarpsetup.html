LocWarp 安裝教學

在 Windows 上模擬 iPhone 定位。照下面四步做完就能用,大約 5 到 10 分鐘。

電腦:Windows 10 / 11(64 位元) 裝置:iOS 17 以上,iOS 16 由社群維護 連線:USB,或同一個 WiFi

四個步驟

1

下載並安裝 LocWarp

抓最新版的 Windows 安裝檔,檔名像 LocWarp-Setup-X.X.XXX.exe。兩個來源內容相同。

GitHub Releases Google 雲端
出現「Windows 已保護您的電腦」 LocWarp 沒有做數位簽章,第一次執行會被 SmartScreen 擋。點「其他資訊」再點「仍要執行」即可。
安裝與執行都需要系統管理員權限 WiFi Tunnel 需要建立虛擬網路介面,所以安裝時會要求管理員權限,每次開啟也會跳 UAC。
防毒軟體把後端程式隔離 開啟後若提示後端程式不存在,是防毒把未簽章的 exe 刪了。先把安裝資料夾加入防毒的排除清單,再重新安裝一次。
2

安裝 Apple USB driver

Windows 沒有內建 Apple 的 USB driver。下列三種擇一安裝即可,多數人裝桌面版 iTunes 就能用。

桌面版 iTunes(64-bit) Store 版 iTunes Apple Devices
iTunes 抓不到 iPhone 社群回報改裝 Microsoft Store 的 Apple Devices 可以成功。
3

USB 連接並信任電腦

用原廠或支援資料傳輸的 USB 線接上 iPhone。iPhone 跳出「要信任這部電腦嗎?」時點「信任」並輸入密碼。

沒跳提示、或電腦抓不到手機 先打開 iTunes 或 Apple Devices 看有沒有偵測到裝置。連 iTunes 都看不到,多半是線或孔的問題:
  • 很多副廠線、附贈線只能充電,沒有資料腳位。換原廠線或標示支援資料傳輸的線。
  • 接頭鬆動或進灰塵會時好時壞,換線並清乾淨兩端。
  • 改插主機板後方的 USB 孔,避開前面板、延長線、USB hub 與螢幕上的孔。
  • USB 3.x(藍色孔)對 iPhone 有時反而不穩,試試 USB 2.0(黑色孔),反過來也試。
  • iPhone 要解鎖並停在桌面。之前誤按「不信任」的話,到「設定 › 一般 › 移轉或重置 iPhone › 重置 › 重置位置與隱私權」,重插就會再問一次。
  • 最後才試 iPhone 與電腦各重開一次。
4

開啟開發者模式

在 iPhone 上前往:

設定›隱私權與安全性›開發者模式

打開開關,iPhone 會要求重新啟動。重啟後再確認一次「啟用」並輸入密碼。

設定裡找不到「開發者模式」 iOS 16 以上預設不顯示這個選項。用 USB 把 iPhone 連上 LocWarp,到程式上方的「設定」頁按「開啟開發者模式」。接著在 iPhone 上把「設定」App 完全關掉再重開,進到「隱私權與安全性」往下拉就會看到。
完成 開啟 LocWarp、USB 接上 iPhone,程式會自動抓到裝置,在地圖上按右鍵就能瞬移。要改用無線時,到「連線」頁啟動 WiFi Tunnel,成功後即可拔掉 USB(需 iOS 17 以上,且先用 USB 配對過一次)。

常見問題

打開程式直接閃退、黑畫面或卡住 通常是顯示卡驅動與硬體加速不合。對桌面的 LocWarp 捷徑按右鍵 › 內容 › 目標,在最後面(結尾引號之後)空一格補上: --no-sandbox --disable-gpu --in-process-gpu 按「確定」後再從這個捷徑開啟。
畫面殘影或黑畫面到「設定」頁關閉硬體加速,重啟程式。
Tunnel 啟動後連不上確認以系統管理員身分啟動,暫時關閉 VPN 或第三方防火牆再試。
WiFi 自動偵測找不到裝置確認在同一個 WiFi 網段,路由器沒開裝置隔離(AP isolation)。可改為手動輸入 IP。
WiFi Tunnel 螢幕暗掉就斷線把 iPhone 的「自動鎖定」設為永不並接上充電,或在 LocWarp 開啟「螢幕暗掉維持連線」。
No such service: dtservicehubDDI 沒掛上。失敗時先關閉開發者模式、重開機、再開啟,然後重新掛載。
國旗或地名沒出現這兩項來自免費公共服務,偶爾會暫時無回應,稍後再瞬移一次即可。

回報問題請附上 iOS 版本、連線方式,以及 ~/.locwarp/logs/backend.log。狀態列的「Log 資料夾」按鈕可以直接開啟該資料夾。

功能簡介

移動模式

瞬間移動直接跳到指定座標。
導航移動沿真實道路前往目的地,走路、腳踏車、開車三檔速度。
多點路徑依序經過多個點,每站可停留(預設隨機 5 到 20 秒)。圈數設 0 跑一趟,設 N 繞 N 圈,留空無限循環。可勾「點對點跳躍」改成逐點瞬移。
花農專用在每個路徑點周圍繞圈。繞圈距離、段數、圈數、輪數、前後等待都可自訂,點與點之間可走過去或瞬移。
隨機漫步在指定半徑內隨機漫遊,每段停頓可調。
搖桿操控以方向與力度即時操控,支援 WASD 與方向鍵。

速度

  • 三檔預設:走路 10.8、腳踏車 19.8、開車 60 km/h。
  • 可輸入任意固定速度,或最小到最大的隨機範圍,每段路重新抽一次。
  • 移動中可以改速度後「套用新速度」,不用停下重來。

路徑來源

四個免費免註冊的引擎可切換:OSRM 公用 demo(預設)、OSRM FOSSGIS、Valhalla、BRouter。任一引擎失敗時該段自動改走直線,也可直接勾「使用直線路徑」。多點路徑有「最佳順序」一鍵算出最短走訪順序。

連線

  • USB:插上自動連線,iPhone 鎖定螢幕不受影響。拔除約 4 秒內偵測,重插自動恢復。
  • WiFi Tunnel(iOS 17 以上):自動偵測用 mDNS,找不到再掃描區網。連過的 IP 會記住,可「釘選」裝置自動連線與重試。
  • 多裝置:最多同時三台,所有動作同步套用,隨機漫步走一樣的路線。

地圖與座標

  • 圖層:OSM、Google 圖磚(測試)、ESRI 街道與衛星、OpenFreeMap Liberty / Bright / Positron、VersaTiles、NLSC 台灣電子地圖、GSI 日本地理院地圖。全部免 API key。
  • 狀態列顯示目前模擬位置的國旗、地名、天氣與溫度,跨時區時標出時差。
  • 座標收藏:自動帶入地名與國旗,可分類、排序、拖曳,JSON 與 GPX 匯入匯出,數萬筆顯示在地圖上也不卡。
  • 路線可分類儲存並直接載入,支援 GPX 與 JSON。
  • 地址搜尋:免費來源(OpenStreetMap 或 Photon),或自備 Google Geocoding 金鑰。
  • 使用者圖示可換成 6 組內建角色或上傳自己的 PNG。

手機網頁操控

按狀態列的「手機操控」會顯示區網網址與 6 位數 PIN,手機瀏覽器輸入後可瞬移、導航、搜尋地址、輸入座標、停止與還原。手機要與電腦在同一個 WiFi,電腦防火牆放行 8777 port。

其他

  • 一鍵還原清除虛擬定位。「停止」只結束移動,定位仍保留,要恢復真實 GPS 請按還原。
  • Cooldown 依瞬移距離自動計算冷卻時間。
  • 介面可在繁體中文與 English 之間切換。
  • 所有資料存在 ~/.locwarp/,重新安裝不會遺失。
